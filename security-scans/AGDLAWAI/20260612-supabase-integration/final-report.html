AGDLAWAI Supabase Integration Security Report

Date: 2026-06-12
Branch: codex/supabase-auth-integration

Scope

Reviewed the Supabase/Auth integration changes for AGDLAWAI, including database schema migration, auth/admin flows, payment callback handling, document upload/export routes, API-key storage, and dependency advisories.

Fixed Findings

Reserved admin email self-registration

frontend/src/app/api/auth/signup/route.ts blocks public signup for emails reserved by SUPER_ADMIN_EMAILS or ADMIN_EMAILS.

Admin mutation of environment-derived admins

frontend/src/app/api/admin/users/[userId]/route.ts resolves target effective role from both environment and profile role before mutation.

Moyasar invoice replay and mismatch acceptance

frontend/src/app/api/billing/moyasar/callback/route.ts verifies paid status, plan amount, SAR currency, and invoice idempotency. The schema and Supabase migration add unique invoice protection.

ZIP export path traversal filenames

Frontend and backend ZIP download routes sanitize archive entry names and deduplicate collisions.

Unbounded frontend upload buffering

frontend/src/app/api/document-upload.ts rejects files larger than 100 MB before buffering. Local Supabase storage config is aligned to 100MiB.
